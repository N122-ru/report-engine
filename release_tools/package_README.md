# Конструктор отчётов — @PRODUCT@

Версия: `@VERSION@`. Платформа: `@PLATFORM@`.

## Перед первым запуском

1. Распакуйте **весь архив** в отдельную папку с правом записи. Не запускайте программу прямо из архива.
2. Не перемещайте исполняемый файл отдельно: папка `_internal` должна оставаться рядом с ним.
3. Python, Node.js и установка библиотек не нужны. Используйте пакет для своей ОС и архитектуры.
4. `web` — редактор в браузере, которым можно пользоваться без ИИ. `headless` — сервер для ИИ-агента, без браузерного интерфейса. Ни один вариант не содержит собственную нейросеть: для работы с ИИ нужен отдельный MCP-клиент.

Ниже описаны оба варианта. В этом пакете находится только **@PRODUCT@**.

## Вариант web: первый отчёт в браузере

1. В Windows дважды нажмите `start-web.bat`. В Linux откройте терминал в папке пакета и выполните `./start-web.sh` (если нужно, сначала `chmod +x start-web.sh report-engine-web`).
2. Дождитесь запуска сервера. Лаунчер пытается открыть браузер после проверки готовности. Если браузер не открылся, откройте напечатанный URL вручную: по умолчанию `http://127.0.0.1:8000`.
3. Оставьте окно терминала открытым. Введите реквизиты, добавьте текст отчёта и изображения, проверьте предпросмотр и скачайте DOCX.
4. Для остановки нажмите `Ctrl+C` в окне сервера. Адрес доступен только на этом компьютере; открывать порты в брандмауэре не нужно.

### Подключение ИИ к открытому отчёту

1. В редакторе откройте окно **«ИИ-агент (MCP)»**.
2. На вкладке **«Команда агенту»** скопируйте готовую инструкцию и отправьте её своему ИИ-агенту. Агенту нужны права настройки MCP и поддержка транспорта SSE. Обычный чат без MCP-инструментов не сможет подключиться.
3. Инструкция содержит адрес вашей сессии. Агент должен подключиться и прочитать правила `report://rules/gost732`, затем получить состояние отчёта перед изменениями. Не публикуйте адрес с токеном.
4. Если агент не умеет настраивать подключение сам, используйте вкладки **«SSE URL»** или **«JSON»** этого же окна: перенесите текущие настройки в MCP-клиент и переподключите его.
5. Не закрывайте вкладку редактора во время работы агента. Если соединение или токен устарели, снова скопируйте актуальную инструкцию из окна MCP. После смены токена старое подключение больше не подходит.

Этот вариант использует SSE, а не stdio. Не подключайте `report-engine-web` как stdio-сервер.

## Вариант headless: подключение к MCP-клиенту

При двойном нажатии `start-headless.bat` программа объясняет назначение и ждёт клиента. Это **не зависание**, но открытое окно само по себе не подключает ИИ. Для ручной проверки в Linux выполните `./start-headless.sh`; остановка — `Ctrl+C`.

Для работы настройте MCP в ИИ-агенте с поддержкой **stdio**:

1. Создайте папку для готовых файлов, например `output` внутри распакованного пакета. Она должна существовать и быть доступна для записи.
2. Добавьте MCP-сервер: команда — **полный путь к исполняемому файлу**, аргументы — `--output-dir` и **полный путь к папке вывода**. Рекомендуется бинарник напрямую, без лаунчера.
3. Пример для Windows; замените оба пути на свои. В JSON обратные слеши записываются дважды:

```json
{
  "mcpServers": {
    "report-engine": {
      "command": "C:\\ReportEngine\\report-engine-headless.exe",
      "args": ["--output-dir", "C:\\ReportEngine\\output"]
    }
  }
}
```

Для Linux замените `command` на `/path/to/report-engine/report-engine-headless`, а путь в `args` — на `/path/to/report-engine/output`. Имена полей конфигурации могут отличаться в вашем MCP-клиенте; выбирайте транспорт stdio и эти же команду и аргументы.

4. Переподключите MCP-сервер в клиенте. Убедитесь, что агент видит `create_report`, `get_report_state` и `export_report`.
5. Попросите агента прочитать `report://rules/gost732`, создать отчёт через `create_report`, заполнить разделы и экспортировать `report.docx`. Перед экспортом агент должен получить свежие `revision`, `meta_revision` и `image_revision` через `get_report_state`.
6. Готовый файл появится в папке вывода. Имя экспортируемого файла задаётся без пути. Существующие файлы не перезаписываются — для следующего экспорта укажите новое имя.

Отчёт и изображения headless хранятся только в памяти до остановки процесса. Явно экспортируйте результат **до** отключения клиента. Один процесс ведёт один отчёт; для нового отчёта завершите текущий и запустите новый процесс.

## DOCX, PDF и шрифты

DOCX доступен независимо от офисного конвертера. Пакет не содержит LibreOffice, OnlyOffice или системные шрифты для документов. Браузерные шрифты формул входят в web-сборку, но не устанавливаются в ОС.

PDF активируется только при обнаружении рабочего локального CLI-конвертера (`soffice`/`libreoffice` или `docbuilder`). Если PDF недоступен, скачайте DOCX и экспортируйте его в PDF вручную через Microsoft Office, LibreOffice или OnlyOffice. Для одинаковой вёрстки на другом компьютере нужны подходящие шрифты, в том числе Times New Roman.

## Устранение неполадок

- **Окно закрывается или программа не запускается.** Запустите лаунчер из терминала и прочитайте сообщение. В Windows при ошибке лаунчер ждёт нажатия клавиши. Проверьте ОС/архитектуру пакета и распакуйте архив целиком заново. Если защитное ПО заблокировало файл, проверьте источник и сообщение блокировки; не отключайте защиту вслепую.
- **Порт занят.** Закройте предыдущий сервер или выполните `start-web.bat --port 8001` в Windows / `./start-web.sh --port 8001` в Linux. Откройте `http://127.0.0.1:8001`. Инструкцию MCP копируйте заново из этого интерфейса.
- **Браузер не открылся автоматически.** Откройте URL вручную. Автооткрытие в Windows требует PowerShell, в Linux — графическую сессию, `curl` и `xdg-open` или `gio`. Отсутствие этих средств не мешает запуску сервера.
- **Headless ждёт и ничего не делает.** Это stdio-сервер, не чат. Настройте его запуск из MCP-клиента; не вводите обычный текст в консоль и не ждите браузера.
- **MCP не подключается.** Для headless проверьте полные пути, существование папки вывода и stdio. Для web оставьте сервер и вкладку открытыми, проверьте SSE и скопируйте свежую инструкцию с токеном. Не используйте настройки одного варианта для другого.
- **Нет прав на папку вывода.** Перенесите пакет в доступную папку или задайте другую существующую папку в `--output-dir`. Для headless-лаунчера также можно задать `REPORT_ENGINE_OUTPUT_DIR`.
- **Экспорт DOCX сообщает об отсутствующем XML/шаблоне.** Проверьте целостность папки `_internal` и распакуйте актуальный пакет заново; не копируйте отдельные файлы из исходников.
- **После перезапуска потерян отчёт.** Headless не сохраняет черновики автоматически. Web сохраняет текст и изображения в хранилище браузера; очистка этого хранилища может привести к потере. Скачивайте результаты заранее.
- **Linux сообщает о несовместимой glibc.** Нужна сборка для совместимой версии Linux; установка Python или Node.js это не исправит.
